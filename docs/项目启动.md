# Agent 运行时安全开发项目启动

## 项目定位

本目录用于承载 AI Agent 运行时安全产品的新一轮开发。当前不绑定历史项目实现，按生产级平台方向重新抽象能力边界、工程架构和验证体系。

## 北极星目标

让企业在使用 AI Agent 执行业务任务时，能够看见、控制、审计和持续优化 Agent 的运行时行为，降低越权访问、敏感数据泄露、工具误用、供应链污染和不可追责执行风险。

## 第一阶段目标：生产基础骨架

| 方向 | 说明 |
|---|---|
| 事件采集 | 采集 Agent 运行时的 prompt、tool call、response、文件访问、网络访问和审批记录 |
| 策略检查 | 支持基于身份、工具、资源、数据类型和业务上下文的规则判断 |
| 风险处置 | 支持 allow、deny、redact、require approval、record 等动作 |
| 审计记录 | 能按任务、Agent、工具、用户、资源维度回放运行记录 |
| HTTP API | 提供 healthz、evaluate、audit events |
| 测试体系 | 覆盖领域模型、策略引擎、审计存储、运行时服务和 API |
| Harness 接入 | 所有开发迭代通过 `ai-dev-harness` 生成 change、task、报告 |

## 工程原则

- 先定义运行时安全事件模型，再选择具体技术栈。
- 先构建可验证闭环，再扩展 UI、集成和高级策略。
- 先做客户高频场景，再做泛化能力。
- 每个迭代都要有明确验收命令和运行报告。
